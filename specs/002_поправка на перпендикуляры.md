## 2. Формулы (СВЕРЕНО с текстовым слоем, прямые цитаты)
Misplacement of marks (стр. 24 книги / PDF index 32):
```
Correction forward = apparent_trim x distance(D FP to Df) / distance(Da to Df)
Midships correction = apparent_trim x distance(D M to Dm) / distance(Da to Df)
Correction aft      = apparent_trim x distance(D AP to Da) / distance(Da to Df)
apparent trim = Da - Df
```
Правило знака (цитата, стр. 24): «If the direction of misplacement of the
draught mark from the perpendicular (or midships position) is the same as the
direction of the trim, then the correction is negative (-) when applied to the
observed draught.» Even keel — поправки не требуются.

Наклон маркерной линии (стр. 25): corr = tan(alpha) × x
(печатано: Tan 22° × 4.121 = 1.665 м).

Hull deflection (EXAMPLE, стр. 25): для hogged/sagged судна вместо общего
trim берут half-trim между миделевой маркой и данным концом:
```
corr_end = misplacement x trim(half) / (half_length - misplacement)
```

## 3. Переменные и единицы
| Символ | Смысл | Единица |
|--------|-------|---------|
| Df, Da | наблюдаемые осадки у марок | м |
| apparent trim | Da − Df (+ = by the stern) | м |
| dist FP→Df, AP→Da | смещения марок от перпендикуляров | м |
| LBP−Σсмещений | length between marks (distance Da to Df) | м |

## 4. Порядок вычислений
1. От SLL до фактической ВЛ: x = SLldraught − Df; смещение марки = tan(rake)×x + отметка марки.
2. Length between marks = LBP − (смещения fwd + aft).
3. Поправки по формулам раздела 2 со знаком правила.
4. При hog/sag — метод half-trim (deflection_end_correction).

## 5. Контрольный пример из книги (QUESTION 3, стр. 24–25)
Df=6.35, Da=7.88, DM=7.12; fwd mark 0.15 м за линией форштевня @SLL, rake 22°,
SLL draught 10.471; aft mark 6.00 м впереди AP; LBP=170.
Apparent trim 1.53; trig 1.665; dist FP 1.815; marks 162.185;
corr F = −0.017 → 6.333 м; corr A = +0.057 → 7.937 м. ✔ тестиров.
EXAMPLE deflection: 2×0.4/48=0.017→5.983; 5×1.0/45=0.111→7.511 ✔.

## 6. Неоднозначности и особые случаи
- Midships correction реализована через ту же схему (DM-марка); отдельного
  численного примера в книге нет — при hog/sag применять half-trim метод.
- OCR читает «0.15 m» как «O.lS»/«0.1) III» — консолидировано по арифметике
  1.665+0.15=1.815 (самосогласованно).
