# 003. Arithmetic Mean Draught (AMD)

## 1. Источник
- Книга: W.J. Dibble, "Draught Surveys — A Guide to Good Practice"
- Страницы: стр. 18 книги (определение), стр. 35–36 (hog/sag, методы 2/3)
- Текст: `sources/text/dibble.txt` (текстовый слой PDF).

## 2. Формула (СВЕРЕНО — цитата стр. 18)
"The arithmetical mean of the forward draught and the aft draught will equal
the draught midships if there is no hog- or sag, this is called the arithmetic
mean draught."
```
AMD = (DF + DA) / 2
```
ВАЖНО: распространённая схема 1-6-1 в книге — НЕ AMD; это Mean Adjusted
Draught метода 2(i) для finer-lined судов (стр. 36): MAD = (DF+DA+6·DM)/8.
Реализованы раздельно (draughts.arithmetic_mean_draught vs
draughts.simpson_weighted_draught / amd_finer_form).

Классификация прогиба (стр. 35, цитата): «If the actual draught is less than
AMD then the vessel is hogged. If the actual draught is greater than AMD then
the vessel is sagged.» → draughts.hog_sag(DM, AMD).

## 3. Переменные и единицы
| Символ | Смысл | Единица |
|--------|-------|---------|
| DF, DA | осадки на FP/AP (после spec 002) | м |
| DM     | миделевая осадка (средняя борт/борт) | м |
| AMD    | (DF+DA)/2 | м |

## 4. Порядок вычислений
1. Spec 002: привести осадки к перпендикулярам.
2. DM = (DM_port + DM_stbd)/2.
3. AMD = (DF+DA)/2; сравнить с DM → hog/sag/even.
4. При прогибе — MAD по методам 2/3 (spec 003b).

## 5. Контрольный пример из книги
EXAMPLE стр. 35 (PDF index 38): DF=6.00, DA=7.40 → AMD=6.70; DM=6.40 < AMD →
vessel is hogged ✔ (тест test_hog_sag_classification).
Q6: (5.80+6.20)/2 = 6.00 ✔ (test_question6_fuller_form_amd).
