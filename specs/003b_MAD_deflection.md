# 003b. Mean Adjusted Draught (MAD) — поправка на прогиб корпуса (deflection)

## 1. Источник
- Книга: W.J. Dibble, "Draught Surveys — A Guide to Good Practice"
- Страницы: 29–30 книги (PDF index 36–38), QUESTION 5 и QUESTION 6, Method 3
- Файл: `sources/text/dibble.txt` (текстовый слой; строки 1124–1200 дампа)

## 2. Формулы (СВЕРЕНО с текстовым слоем)
Шаг 1 — AMD в зависимости от формы корпуса:
```
finer-lined (sleek) vessel :  AMD = (6·DM + DF + DA) / 8     # Q5, OCR "(G x G,ll)+5.G4+(JA2/H"
fuller-form vessel         :  AMD = (DF + DA) / 2            # Q6, печатается явно: (5.80+6.20)/2 = 6.00
```
Шаг 2 — factor из графика «признак полноты» по коэффициенту полноты
ватерлинии Cw (ось X 0.6…0.9; в книге график повреждён OCR, считывается
только точка Cw=0.60 → factor=0.76):
```
Mean adjusted draught = AMD + factor × (DM − AMD)            # цитата стр. 29
```
Альтернатива 1 (сразу в тоннах, стр. 30):
```
Correction (tonnes) = factor × TPC × hog/sag(cm),  hog/sag(cm) = (DM − AMD) × 100
```
Альтернатива 2: таблица factor×TPC на каждый см hog/sag.

## 3. Переменные и единицы
| Символ | Смысл | Единица |
|--------|-------|---------|
| DF, DA | осадки на FP/AP (после spec 002) | м |
| DM | осадка на миделе (средняя борт/борт) | м |
| Cw | коэффициент полноты ватерлинии (из booklet) | — |
| factor | 0…1 с графика | — |
| MAD | окончательная средняя осадка | м |

## 4. Контрольные примеры (выведены консолидацией OCR)
- **Q5**: DF=5.64, DA=6.42, DM=«G.ll». Единственный самосогласованный
  вариант DM=6.03 → (6·6.03+5.64+6.42)/8 = **6.03 ровно** (ответ книги
  «(i.()~) m»). Альтернативная читка DM=6.12 → 6.0975 — зафиксирована в тесте.
- **Q6**: DF=5.80, DA=6.20, DM=6.18 («6.) 8»), Cw=0.60 → factor=0.76:
  AMD=6.00, MAD = 6.00 + 0.76·0.18 = **6.1368**. Печатный ответ «G.t:n»
  читаем как 6.13 (t↔3 — типовая конфузия скана); математическое
  округление даёт 6.14. Открытый вопрос к скану.
