## 2. Порядок применения поправок (как в книге)
```
OBSERVED DRAUGHTS (F/aft/mid, P&S) -> mean values (centreline)
1. Correct from marks to perpendicular and midships positions:
     misplacement OPPOSITE to trim -> positive (+)
     misplacement SAME as trim     -> negative (-)
2. Hog/sag correction (mean of mean of means, or similar):
     negative (-) for hog
     positive (+) for sag
-> CORRECTED MEAN DRAUGHT (вход в гидростатику)
-> Displacement from displacement table
3. First trim correction / layer (tonnes):
     LCF SAME as trim      -> positive (+)
     LCF OPPOSITE to trim  -> negative (-)
4. Second trim correction (tonnes): always positive (+)
5. List correction (tonnes): always positive (+)
6. Correction for density:
     less than salt water density -> negative (-)
-> CORRECTED DISPLACEMENT
```
Замечание ASSESSMENT SUMMARY (стр. 45): поправки 1st/2nd trim, list и density
книга рекомендует считать СРАЗУ В ТОННАХ и применять к водоизмещению из
гидростатической таблицы (не к осадке) — согласуется с правилом плотности №3/№4
(spec 001) и реализовано в src/trim.py, src/list_correction.py,
src/density.py.

## 3. Кросс-проверка со спецификациями 001–003b (вывод, а не слепое доверие OCR)
- Пункт 1 ↔ spec 002: правило «same direction → (−)» — прямая цитата стр. 24;
  Q3: trim by stern, марки смещены «по триму» на носу → −0.017 ✔.
- Пункт 2 ↔ spec 003b: для HOGGED судна MAD < AMD (Q5/Q6: DM 6.03–6.18 против
  AMD 6.00–6.03, поправка вычитается из «грубого» среднего) — знак (−) за hog
  подтверждается EXAMPLE стр. 25 (5.983 < 6.00 при hog) ✔.
- Пункт 3 ↔ src/trim.py first_trim_correction_t_sign: «LCF same as trim → +»
  эквивалентно таблице стр. 31 (LCF fwd & trim aft → −) ✔ (оба теста).
- Пункты 4–5 ↔ second_trim_correction_t / list_correction_t: константа знака (+)
  зафиксирована цитатами стр. 32/26 ✔.
- Пункт 6 ↔ displacement_density_correction_t: rho1<rho2 ⇒ множитель <1 ⇒
  водоизмещение уменьшается = «negative» ✔ (Q9: 15250→15101.2).
