## Правила работы с переводами
1. Перевод — источник русской терминологии для мемуаров (MEMOIRS-RU).
2. Любое числовое утверждение из перевода проверяется по оригиналу до попадания в код/тесты.
3. Расхождения фиксируются в specs/discrepancies.md.
