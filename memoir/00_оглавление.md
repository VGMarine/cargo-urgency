# Книга расчётов по осадке (мемуары)

Русское издание, объединяющее лучшее из трёх первоисточников:
- G. W. Dibble «Draught Survey» (черновик, все формулы и примеры сверены арифметически);
- «Draft Survey Guidance» (хорошая практика);
- UNECE Draft Survey Code 1992 (порт программы BASIC — этап 7).

Каждый расчёт показан дважды: словами+формулой (как в книге) и функцией Python с тестом.

## Части
1. [Часть I. Осадки и наблюдения](01_осадки.md) — отсчёт marks, перпендикуляры, наклон, крен, плотность воды
2. Часть II. Дифферент и средние осадки — AMD, LCF, поправки слоя (этап 6)
3. Часть III. Зондирование танков — sounding, клинья, объёмы (этап 6)
4. Часть IV. Таблица грузоподъёмности, формы A–E (этап 6)
5. Часть V. Программа кодекса ООН (BASIC → Python) (этап 7)

## Статус глав
Главы публикуются по мере прохождения этапа 3 (тест = контрольный пример книги).
